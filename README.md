## الفكرة

المنصة مبنية على فكرة **البنك والشيكات**: المشرف يصدر للطالب شيكاً تحفيزياً بقيمة نقاط،
والطالب يجمع نقاطه ويستبدلها من **المتجر**. النقاط من فئة **٢٥** وتُعادل الريال في الشيك.

## أبرز المزايا

| المزية | التفصيل |
| --- | --- |
| 🧾 **دفاتر الشيكات الفارغة** | اختر نوع الشيك وقيمته (الحضور المبكر ٧٠، الحضور العام ٥٠، حفظ/مراجعة ٢٥، حفظ ومراجعة ٥٠، الانضباط ٢٥) وعدد النسخ، فتُطبع **خمسة شيكات في كل صفحة A4** بخانات اسم وتوقيع فارغة يكتبها المعلم، وفي كل شيك باركود فريد وقيمته بالنقاط. |
| 💳 **صرف الشيك بالمسح** | في شاشة المسح: امسح باركود الشيك ثم بطاقة الطالب، فتُضاف قيمته لرصيده ويُقفل الشيك فلا يُصرف مرتين. ويبقى الشيك القديم باسم الطالب متاحاً لمن يريد إصداره وطباعته مباشرة. |
| 📷 **الباركود** | لكل طالب باركود ثابت (Code128) يظهر في صفحته الشخصية ويُطبع ملصقاً. كل مسحة بقارئ الباركود تضيف ٢٥ نقطة، مع منع المسح المكرر خلال مهلة قابلة للضبط. |
| 🖨️ **طباعة مكثّفة للباركودات** | ثلاث كثافات من قائمة منسدلة: ٢٤ أو ٤٠ ملصقاً في الصفحة الواحدة، أو بطاقة كاملة بالصورة (١٠ في الصفحة). |
| 🏅 **فارس الأسبوع** | يُحتسب تلقائياً من صاحب أعلى نقاط خلال الأسبوع، ويظهر بصورته التي يرفعها بنفسه من صفحته. |
| 🕌 **حلقة الأسبوع** | الحلقة الأعلى نقاطاً (نقاط طلابها + النقاط التي يمنحها المشرف للحلقة). |
| 🏆 **شاشة الصدارة** | شاشة عرض للقاعة بتصميم احترافي تتنقل تلقائياً بين فارس الأسبوع وحلقة الأسبوع ومنصة تتويج الثلاثة الأوائل وترتيب الطلاب والحلقات. |
| 🎁 **المتجر** | جوائز بصور وأسعار بالنقاط يضيفها المشرف، والطالب يطلب الجائزة فتُخصم نقاطه وتصل للمشرف للتسليم (والرفض يعيد النقاط). |
| 👥 **المجموعات** | ترتيب الحلقات ونقاطها ومعدل الطالب فيها، مع إمكانية منح نقاط للحلقة كاملة. |
| 📱 **تطبيق قابل للتثبيت** | واجهة عربية RTL متجاوبة + PWA يمكن تثبيتها على الجوال والآيباد وسطح المكتب. |
| 🔐 **الدخول برقم الجوال** | المشرف يسجّل الاسم ورقم الجوال، والمستخدم يدخل برقم جواله + الرمز المؤقت **1234**، ثم تظهر له مباشرة شاشة إجبارية لاختيار رمزه الخاص. |

## التشغيل

```bash
npm install          # تثبيت الحزم
npm start            # تشغيل الخادم على المنفذ 3000
```

ثم افتح `http://localhost:3000`.

عند أول تشغيل يُنشأ حساب مدير تلقائياً وتظهر بياناته في الطرفية:

```
رقم الجوال: 0500000000
الرمز المؤقت: 1234        (ستظهر شاشة تغيير الرمز مباشرة بعد الدخول)
```

يمكن تحديد رقم جوال المدير مسبقاً عبر متغيرات البيئة:

```bash
ADMIN_PHONE=0551234567 ADMIN_NAME='مشرف المجمع' PORT=8080 npm start
```

### بيانات تجريبية

```bash
npm run seed         # ٤ حلقات و٢٤ طالباً ونقاط وجوائز لتجربة الشاشات
```

### الاختبارات

```bash
npm test             # اختبارات واجهات البرمجة: الشيكات، المسح، المتجر، الصلاحيات
```

## تسجيل الدخول

الدخول من خطوتين، بلا كلمات مرور طويلة:

1. **رقم الجوال** — يتحقق النظام من أن الرقم مسجَّل ويرحّب بصاحبه بالاسم.
2. **رمز الدخول** — الرمز المؤقت للحسابات الجديدة هو **1234** (قابل للتغيير من الإعدادات).
3. **شاشة تغيير الرمز** — تظهر إجبارياً بعد أول دخول، ولا تُفتح أي شاشة أخرى قبل اختيار رمز جديد
   (٤ إلى ٦ أرقام، ويجب أن يختلف عن الرمز المؤقت). الحماية مطبَّقة في الخادم أيضاً، لا في الواجهة فقط.

**من يسجّل الأرقام؟** المشرف. يضيف الطالب باسمه ورقم جواله من «الأفراد»، ويضيف المدير المشرفين
بأسمائهم وأرقامهم من «الإعدادات». وإذا نسي أحدهم رمزه، يضغط المشرف «إعادة الرمز» فيعود إلى الرمز
المؤقت وتُغلق جلساته، ويُطلب منه اختيار رمز جديد عند الدخول.

يقبل حقل الجوال الصيغ: `0501234567` و `+966501234567` و `966501234567` والأرقام العربية `٠٥٠…`،
وتُخزَّن جميعها بصيغة موحّدة.

## طريقة العمل اليومية

1. **التهيئة**: من «المجموعات» أضف الحلقات، ومن «الأفراد» أضف الطلاب (بالاسم ورقم الجوال، ويمكن لصق دفعة كاملة بصيغة «الاسم، رقم الجوال» في كل سطر).
2. **باركودات الطلاب**: من «الأفراد» → «إجراءات» → «طباعة بطاقات الباركود»، ثم اختر الكثافة (٢٤ أو ٤٠ في الصفحة، أو بطاقة كاملة بالصورة).
3. **الرصد**: افتح «المسح» على جهاز المشرف، ووجّه قارئ الباركود لبطاقة الطالب — كل مسحة تضيف ٢٥ نقطة فوراً (وعدد النقاط يُختار من قائمة منسدلة).
4. **دفاتر الشيكات**: من «الشيكات» → «دفاتر الشيكات الفارغة» اختر نوع الشيك وعدده ثم «إنشاء وطباعة» — خمسة شيكات في الصفحة. يوزّعها المعلم بعد كتابة الاسم والتوقيع، ثم تُصرف من شاشة المسح: باركود الشيك ثم بطاقة الطالب.
5. **شيك باسم طالب** (اختياري): من التبويب الثاني في «الشيكات» اختر البند والطلاب → «إصدار وطباعة»، فتُضاف القيمة لرصيدهم مباشرة.
6. **المتجر**: أضف الجوائز بصورها وأسعارها، وتابع طلبات الطلاب وسلّمها.
7. **شاشة القاعة**: افتح `/screen.html` على شاشة العرض (زر `f` لملء الشاشة، `مسافة` للتنقل اليدوي).

## الأدوار والصلاحيات

- **مدير المنصة**: كل الصلاحيات + الإعدادات وحسابات المشرفين وقيم بنود الشيكات.
- **المشرف**: الطلاب والحلقات والنقاط والشيكات والمسح والمتجر.
- **الطالب**: صفحته الشخصية (نقاطه، باركوده، رفع صورته)، الصدارة، المتجر وطلباته.

لكل طالب باركود ثابت للرصد (مثل `RQ00012`) مستقل عن رقم جواله المستخدم في الدخول،
ولكل شيك فارغ باركود خاص يبدأ بـ `RQC` لا يُصرف إلا مرة واحدة.

## الهوية البصرية

ألوان المنصة مستمدة من شعار جمعية رواسم: الأزرق البترولي `#123f52` والتركوازي `#2e7085`
والأخضر الفاتح `#7fbfae` والبرتقالي `#f0951f`، وهي معرّفة كمتغيّرات CSS في
`public/css/app.css` وتتكرر في أوراق الطباعة وشاشة العرض. أيقونات الواجهة رسوم SVG خطية
موحّدة في `public/js/icons.js`.

## التثبيت كتطبيق

افتح الموقع في المتصفح ثم:

- **آيفون/آيباد**: زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **أندرويد/كروم**: القائمة ← «تثبيت التطبيق».
- **ويندوز/ماك**: أيقونة التثبيت في شريط العنوان.

> التثبيت يتطلب تشغيل الموقع عبر HTTPS (أو `localhost` أثناء التجربة).

## النشر

المستودع على GitHub: <https://github.com/msnd7/t-aog>. دليل التفعيل خطوة بخطوة في
**[DEPLOY.md](DEPLOY.md)**: Fly.io أو Vercel أو Render أو خادم خاص أو Docker، وكلها تُربط
بالمستودع لنشر كل تحديث تلقائياً.

- الخادم لا يحتاج قاعدة بيانات خارجية على استضافة بقرص دائم؛ كل شيء داخل `data/app.db`.
  **خذ نسخة احتياطية من مجلد `data/` دورياً.**
- على الاستضافات بلا قرص دائم (Vercel) لا بد من قاعدة بعيدة: إمّا **Postgres** بضبط
  `POSTGRES_URL`/`DATABASE_URL` (تكامل Neon الذي يضيفه Vercel تلقائياً من تبويب Storage)،
  أو **libSQL/Turso** بضبط `TURSO_DATABASE_URL`. وحينها تُحفظ الصور المرفوعة داخل قاعدة
  البيانات تلقائياً في الحالتين. التفاصيل في [DEPLOY.md](DEPLOY.md).
- خلف وكيل عكسي (Nginx/Caddy) مع HTTPS، شغّل الخادم بـ `COOKIE_SECURE=1` لتأمين ملف الجلسة.
- متغيرات البيئة المدعومة: `PORT`، `DATA_DIR`، `ADMIN_PHONE`، `ADMIN_NAME`، `COOKIE_SECURE`، `TZ`،
  و`POSTGRES_URL`/`DATABASE_URL` (Postgres)، أو `TURSO_DATABASE_URL` مع `TURSO_AUTH_TOKEN` (libSQL).
- ملفات جاهزة في المستودع: `Dockerfile` · `fly.toml` · `render.yaml` · `vercel.json` · `api/index.js` ·
  `deploy/nginx.conf` · `deploy/riyad-quran.service`.

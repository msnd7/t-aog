## الفكرة

المنصة مبنية على فكرة **البنك والشيكات**: المشرف يصدر للطالب شيكاً تحفيزياً بقيمة نقاط،
والطالب يجمع نقاطه ويستبدلها من **المتجر**. النقاط من فئة **٢٥** وتُعادل الريال في الشيك.

## أبرز المزايا

| المزية | التفصيل |
| --- | --- |
| 🧾 **الشيكات** | ثلاثة دفاتر جاهزة للطباعة: الحضور (مبكر ٧٠ / عام ٥٠)، تسميع الورد اليومي (حفظ ٢٥، مراجعة ٢٥، حفظ ومراجعة ٥٠)، الانضباط والأخلاق ٢٥ — كل شيك يحمل اسم الطالب والحلقة والبند والمبلغ رقماً وتفقيطاً وخانتَي توقيع المعلم والمشرف. |
| 📷 **الباركود** | لكل طالب باركود ثابت (Code128) يظهر في صفحته الشخصية ويُطبع في بطاقة. كل مسحة بقارئ الباركود تضيف ٢٥ نقطة، مع منع المسح المكرر خلال مهلة قابلة للضبط. |
| 🏅 **فارس الأسبوع** | يُحتسب تلقائياً من صاحب أعلى نقاط خلال الأسبوع، ويظهر بصورته التي يرفعها بنفسه من صفحته. |
| 🕌 **حلقة الأسبوع** | الحلقة الأعلى نقاطاً (نقاط طلابها + النقاط التي يمنحها المشرف للحلقة). |
| 🏆 **شاشة الصدارة** | شاشة عرض للقاعة تتنقل تلقائياً بين فارس الأسبوع وحلقة الأسبوع وترتيب الطلاب والحلقات. |
| 🎁 **المتجر** | جوائز بصور وأسعار بالنقاط يضيفها المشرف، والطالب يطلب الجائزة فتُخصم نقاطه وتصل للمشرف للتسليم (والرفض يعيد النقاط). |
| 👥 **المجموعات** | ترتيب الحلقات ونقاطها ومعدل الطالب فيها، مع إمكانية منح نقاط للحلقة كاملة. |
| 📱 **تطبيق قابل للتثبيت** | واجهة عربية RTL متجاوبة + PWA يمكن تثبيتها على الجوال والآيباد وسطح المكتب. |
| 🔐 **الدخول برقم الجوال** | المشرف يسجّل الاسم ورقم الجوال، والمستخدم يدخل برقم جواله + الرمز المؤقت **1234**، ثم تظهر له مباشرة شاشة إجبارية لاختيار رمزه الخاص. |

## التشغيل

```bash
npm install          # تثبيت الحزم
npm start            # تشغيل الخادم على المنفذ 3000
```

ثم افتح `http://localhost:3000`.

عند أول تشغيل يُنشأ حساب مدير تلقائياً وتظهر بياناته في الطرفية:

```
رقم الجوال: 0500000000
الرمز المؤقت: 1234        (ستظهر شاشة تغيير الرمز مباشرة بعد الدخول)
```

يمكن تحديد رقم جوال المدير مسبقاً عبر متغيرات البيئة:

```bash
ADMIN_PHONE=0551234567 ADMIN_NAME='مشرف المجمع' PORT=8080 npm start
```

### بيانات تجريبية

```bash
npm run seed         # ٤ حلقات و٢٤ طالباً ونقاط وجوائز لتجربة الشاشات
```

### الاختبارات

```bash
npm test             # اختبارات واجهات البرمجة: الشيكات، المسح، المتجر، الصلاحيات
```

## تسجيل الدخول

الدخول من خطوتين، بلا كلمات مرور طويلة:

1. **رقم الجوال** — يتحقق النظام من أن الرقم مسجَّل ويرحّب بصاحبه بالاسم.
2. **رمز الدخول** — الرمز المؤقت للحسابات الجديدة هو **1234** (قابل للتغيير من الإعدادات).
3. **شاشة تغيير الرمز** — تظهر إجبارياً بعد أول دخول، ولا تُفتح أي شاشة أخرى قبل اختيار رمز جديد
   (٤ إلى ٦ أرقام، ويجب أن يختلف عن الرمز المؤقت). الحماية مطبَّقة في الخادم أيضاً، لا في الواجهة فقط.

**من يسجّل الأرقام؟** المشرف. يضيف الطالب باسمه ورقم جواله من «الأفراد»، ويضيف المدير المشرفين
بأسمائهم وأرقامهم من «الإعدادات». وإذا نسي أحدهم رمزه، يضغط المشرف «إعادة الرمز» فيعود إلى الرمز
المؤقت وتُغلق جلساته، ويُطلب منه اختيار رمز جديد عند الدخول.

يقبل حقل الجوال الصيغ: `0501234567` و `+966501234567` و `966501234567` والأرقام العربية `٠٥٠…`،
وتُخزَّن جميعها بصيغة موحّدة.

## طريقة العمل اليومية

1. **التهيئة**: من «المجموعات» أضف الحلقات، ومن «الأفراد» أضف الطلاب (بالاسم ورقم الجوال، ويمكن لصق دفعة كاملة بصيغة «الاسم، رقم الجوال» في كل سطر).
2. **بطاقات الباركود**: من «الأفراد» → «طباعة بطاقات الباركود» تُطبع بطاقة لكل طالب (٩ بطاقات في صفحة A4).
3. **الرصد**: افتح «المسح» على جهاز المشرف، ووجّه قارئ الباركود لبطاقة الطالب — كل مسحة تضيف ٢٥ نقطة فوراً.
4. **الشيكات**: من «الشيكات» اختر نوع الشيك والبند ثم الطلاب (حلقة كاملة أو أفراد) → «إصدار وطباعة». تُضاف قيمة الشيك لرصيد الطالب تلقائياً.
5. **المتجر**: أضف الجوائز بصورها وأسعارها، وتابع طلبات الطلاب وسلّمها.
6. **شاشة القاعة**: افتح `/screen.html` على شاشة العرض (زر `f` لملء الشاشة، `مسافة` للتنقل اليدوي).

## الأدوار والصلاحيات

- **مدير المنصة**: كل الصلاحيات + الإعدادات وحسابات المشرفين وقيم بنود الشيكات.
- **المشرف**: الطلاب والحلقات والنقاط والشيكات والمسح والمتجر.
- **الطالب**: صفحته الشخصية (نقاطه، باركوده، رفع صورته)، الصدارة، المتجر وطلباته.

لكل طالب باركود ثابت للرصد (مثل `RQ00012`) مستقل عن رقم جواله المستخدم في الدخول.

## التثبيت كتطبيق

افتح الموقع في المتصفح ثم:

- **آيفون/آيباد**: زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **أندرويد/كروم**: القائمة ← «تثبيت التطبيق».
- **ويندوز/ماك**: أيقونة التثبيت في شريط العنوان.

> التثبيت يتطلب تشغيل الموقع عبر HTTPS (أو `localhost` أثناء التجربة).

## النشر

- الخادم لا يحتاج قاعدة بيانات خارجية؛ كل شيء داخل `data/app.db`. **خذ نسخة احتياطية من مجلد `data/` دورياً.**
- خلف وكيل عكسي (Nginx/Caddy) مع HTTPS، شغّل الخادم بـ `COOKIE_SECURE=1` لتأمين ملف الجلسة.
- متغيرات البيئة المدعومة: `PORT`، `DATA_DIR`، `ADMIN_PHONE`، `ADMIN_NAME`، `COOKIE_SECURE`.
